### 1.6 启动器 · 模块运行（启动 / 停止）

v0.1.0 只有「装、配、修、卸」，「跑」完全没有——启动器不能启动模块。
本版补齐，验收项与 `docs/RUNNING.md` §9 对应。

| # | 验收项 | 条目 | 结论 | 证据 |
|---|---|---|---|---|
| RUN1 | 拉起已安装模块，健康通过 → `running` | 启动 | 通过 | `runtime.rs` 11 项 + `running_e2e.rs` 真实子进程 |
| RUN2 | 健康检查超时 → `failed` 且带原因 | 启动 | 通过 | `r2_health_timeout_marks_failed`（指向死端口） |
| RUN3 | 停止回收进程、PID 消失 | 停止 | 通过 | `r1_r3_start_and_stop_real_process` |
| RUN4 | 进程被外部终止 → 状态回落，不显示「在跑」 | 状态 | 通过 | `r4_exited_process_reports_failed`；`view()` 每次查询回收已退出进程 |
| RUN5 | 未安装/已停用/非 command 入口 → 拒绝且原因可读 | 启动 | 通过 | 4 项测试分别覆盖，含缺 manifest 的情况 |
| RUN6 | 一键启动顺序正确且失败不阻塞 | 一键启动 | 通过 | `r6_start_all_follows_order_and_continues_on_failure`（中间模块失败，前后仍启动） |

| RUN9 | 工作目录越界拒绝 | 安全 | 通过 | `r9_rejects_working_dir_escape` + 路径词法复核 |
| RUN10 | 日志不含 stdout 内容 | 隐私 | 通过 | 子进程 stdout/stderr 全部 `Stdio::null()`，不落盘 |
| RUN11 | 卡片「启动/停止」按钮真实可用 | UI | 通过 | 桩渲染验证：运行中显示「停止」、失败显示「重试」、停止显示「启动」 |

接口约定 `model_capabilities` 取值 `["vision","asr","tts","search"]`，
